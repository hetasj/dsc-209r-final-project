DSC 209R Final Project · Initial Prototype

Abortion Access and Travel Across U.S. States

Heta Joshi and Jade Romero

Research question: How did access to abortion care differ across U.S. states before the Dobbs decision, and do high abortion counts tell the same story as access measures such as clinic availability and out-of-state travel?

Hover over a state on the map or in the ranking for its values. Click a state to keep it highlighted in both views, and click it again to clear.

What we have done so far

We have chosen the Guttmacher Institute dataset about abortion access across the U.S. by exporting it into a CSV file. We also created several initial visualizations, including charts about abortion counts, abortion rates, out-of-state travel, clinic availability, and clinic count changes. We made this an interactive USA map colored by the selected measure, tied to a ranked bar chart by each state for that measure. We have a dropdown menu, tooltips, and click to select working.

What will be the most challenging

The most challenging part of this project will be designing a clear story from measures that do not all describe the same thing. Some variables describe where abortions occurred, while others describe where patients lived, how many clinics existed, or whether residents traveled out of state for care. Because these measures use different units (counts, rates, percentages) and come from different years, we need to label each one clearly so readers know which ones can be compared directly versus not. Another challenge is showing cross-state travel when the data only gives state totals, not where patients actually went, so we have to describe patterns carefully without claiming more than the data shows.
